# 创作知识库 · 工作流执行计划

> 实现阶段由 GLM-5.3-Flash 子 Agent 执行；每个任务的输入 = 本目录全部文档 + 明确边界；完成后统一跑质量门禁。整合审核由主会话（GLM-5.3）负责。

## 任务分解

### T1 scaffold（串行，最先）
产出：可运行的空壳 + 全部基础设施。
- `flutter create`（org com.creativekb，platforms windows,android）于 `creative_kb/`；`flutter pub add` 全部依赖（见 01 文档清单）并锁定版本
- `analysis_options.yaml`（flutter_lints + prefer_const 等常规）
- Material 3 中文 App：主题（seedColor 深青色系）、`app.dart`、`features/shell` 响应式导航（五入口占位页）
- drift：tables.dart（01 文档全部表，含 kb_fts 触发器）、database.dart、各表 DAO 与常用查询；build_runner 生成
- riverpod ProviderScope、路由常量表、`shared/` 空 widget 占位
- seed：4 套 Schema JSON 首启落盘逻辑、intensity 4 预设、内置价格常量表
- `.gitignore`、`README.md` 骨架、git init + 首提交
门禁：pub get + analyze 0 error + test 0 失败（此时测试可为 schema/seed 合法性单测）。

### T2 core-llm（并行波 1）
`core/llm/` + `core/storage/` 全部：LlmClient 实现（dio + SSE 手解析）、providers、model_catalog、intensity、structured_output（校验+重试）、secure_keys。按 02 文档 A1-A4。交付对应单测（≥8 用例）。**不得改 pubspec（缺包报告而非自行加）**。

### T3 tasks+usage（并行波 1）
`core/tasks/`（TaskRunner 状态机/重试/超时/额度拦截、usage_ledger）+ `features/usage/` 看板页（今日/累计、模块饼图、模型柱状、明细表——图表用纯 CustomPaint 简单柱状即可，不引图表库）。依赖 T1 的表结构。单测 ≥6。

### T4 fragments（并行波 1）
`features/fragments/` 全部页面与流水线（02 文档 B1-B3），FragmentOptimizeTask 提示词与拆分入库、双版本对比、转提示词草稿/资料条目的跳转约定（路由参数带 fragmentId）。依赖：调用 T2 的 structured_output 接口签名（按文档实现，不等 T2 完成也可先行，最终以接口名为准：`StructuredOutput.request<T>(...)`）。widget 测试 ≥3。

### T5 prompts（并行波 1）
`features/prompts/`（02 文档模块C全部）：三种类型模板常量、3 风格生成、4 方向优化、版本回滚、变量提取与填充复制。单测/ widget 测试 ≥3。

### T6 kb（并行波 1，最大任务）
`features/kb/` + `core/search/`：Schema 注册表管理、五步入库向导、分类树、条目浏览/详情/编辑、FTS+向量混合检索、关联双向链接、极速入库开关、未向量化标记。依赖 T2 接口（embedding 调用）。单测 ≥8（含两个示例场景）。

### T7 集成收尾（串行，波 1 全绿后）
- 设置页全部分组（A2/A3/A6/E）+ 更新检查器 + 导出/导入 zip
- 路由全连通走查：碎片→提示词→资料库转化链路参数一致
- 首页空态引导、README 完整化、CI 两个 workflow 文件
- 全量 analyze + test；修复全部 error；git 提交（按任务分 commit）

## 通用约束（写入每个子任务提示词）
1. 只创建/修改自己目录与 `lib/core` 内自己负责的文件；pubspec.yaml/路由表（T1 定稿）如需变更：**不直接改**，在返回报告中说明
2. 门禁命令见 03 文档；跑之前先 build_runner（涉表变更时）
3. 中文 UI 文案；代码注释仅写必要约束说明
4. 完成定义：门禁通过 + 报告（做了什么/偏离规格处/遗留风险）
5. 禁止实现 v2 功能（见 00 文档 D3）
