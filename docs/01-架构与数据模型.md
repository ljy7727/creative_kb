# 创作知识库 · 架构与数据模型

> 技术形态：Flutter 单代码库（Windows 桌面 + Android）。UI 中文，代码标识符英文。

## 一、分层架构

```
lib/
├── main.dart                      # 入口：初始化 DB/设置/队列，启动 App
├── app.dart                       # MaterialApp、主题、响应式 Shell
├── core/                          # 基础设施层
│   ├── db/
│   │   ├── database.dart          # drift 数据库定义（全部表）
│   │   ├── tables.dart            # 表结构
│   │   └── daos/                  # 每表一个 DAO
│   ├── storage/
│   │   └── secure_keys.dart       # flutter_secure_storage 封装（API Key）
│   ├── llm/
│   │   ├── llm_client.dart        # OpenAI 兼容客户端：chatStream / listModels / embed
│   │   ├── providers.dart         # 厂商预设 + 自定义；Key 引用管理
│   │   ├── model_catalog.dart     # 模型拉取 + 启发式标签
│   │   ├── intensity.dart         # 4 档思考强度预设 + 自定义
│   │   └── structured_output.dart # JSON 结构化输出 + Schema 校验 + 自动重试
│   ├── tasks/
│   │   ├── task_runner.dart       # 异步任务队列（状态机、重试、超时）
│   │   └── usage_ledger.dart      # token 记账 + 额度防护
│   ├── search/
│   │   ├── fts_index.dart         # FTS5 全文索引维护与查询
│   │   ├── vector_index.dart      # 嵌入存储 + 余弦相似度检索
│   │   └── hybrid_search.dart     # 关键词 + 语义混合排序
│   └── update/
│       └── update_checker.dart    # GitHub Releases 检查 + semver 比对
├── features/                      # 业务模块层（每模块 models/ services/ pages/ widgets/）
│   ├── shell/                     # 响应式导航壳（Rail/BottomBar 切换）
│   ├── settings/                  # 厂商&Key、模型、预设、额度、更新、导入导出
│   ├── fragments/                 # 模块1：灵感碎片
│   ├── prompts/                   # 模块2：提示词库
│   ├── kb/                        # 模块3：资料库（分类树/入库向导/条目浏览/检索）
│   └── usage/                     # 用量统计看板
└── shared/                        # 跨模块 widgets（Markdown 渲染、标签 chips、流式文本框、空态引导）
```

状态管理统一用 `flutter_riverpod`（`ProviderScope` 在 main；每 feature 用 `Notifier` + `AsyncNotifier`）。路由用 Navigator 2 简化版（onGenerateRoute + 路由常量表），不引入 go_router 以减依赖。

## 三、SQLite 数据模型（drift 表定义，字段名即列名）

```
providers        (id PK, name, baseUrl, keyRef, presetCode, createdAt)
                 -- presetCode: deepseek|qwen|doubao|zhipu|custom
                 -- 预设 baseUrl：DeepSeek https://api.deepseek.com/v1
                 --   通义 https://dashscope.aliyuncs.com/compatible-mode/v1
                 --   豆包 https://ark.cn-beijing.volces.com/api/v3
                 --   智谱 https://open.bigmodel.cn/api/paas/v4
models           (id PK, providerId FK, modelId TEXT, displayName, tags TEXT(json数组),
                   isActive BOOL, updatedAt)
                 -- tags 取值: general|reasoning|long_context|embedding
intensity_presets(id PK, code TEXT UNIQUE, name, params TEXT(json), isBuiltin BOOL)
                 -- builtin: fast|standard|deep|custom

fragments        (id PK, rawText, optimizedJson TEXT NULL, title, tags TEXT(json),
                   source TEXT('manual'|'ai'), aiMeta TEXT(json: model,preset,tokens,ts),
                   status TEXT('raw'|'optimized'|'failed'), createdAt, updatedAt)
prompts          (id PK, title, type TEXT('novel'|'image'|'agent'), body,
                   variables TEXT(json:[{name,desc}]), category, currentVersionId, createdAt)
prompt_versions  (id PK, promptId FK, body, note, createdAt)

kb_categories    (id PK, path TEXT UNIQUE, parentId)          -- path 形如 "仙侠设定/势力宗门"
kb_entries       (id PK, entryName, categoryPath, tags TEXT(json), summary,
                   contentMd, extra TEXT(json 分类扩展字段), related TEXT(json:[entryName]),
                   source, credibility TEXT('high'|'mid'|'low'), createdAt, updatedAt)
kb_relations     (id PK, entryId, relatedEntryId)             -- 双向各存一行，两列建索引
embeddings       (entryId PK, model, dim INT, vector BLOB)    -- float32 小端序列化
kb_fts           (FTS5 虚表: entryName, summary, contentMd; 内容表 kb_entries 触发器同步)

usage_log        (id PK, ts, module, taskType, providerName, model, presetCode,
                   inputTokens, outputTokens, costEstimate REAL NULL, durationMs,
                   status TEXT('ok'|'error'|'blocked'), error TEXT NULL)
task_queue       (id PK, module, taskType, payload TEXT(json), status
                   TEXT('pending'|'running'|'success'|'failed'|'cancelled'),
                   result TEXT NULL, error TEXT NULL, retries INT DEFAULT 0,
                   createdAt, startedAt, finishedAt)
app_settings     (key PK, value TEXT)   -- 单次上限/日上限/默认强度/极速入库开关/更新仓库 owner/repo 等
```

额度防护：TaskRunner 执行前查当日 `usage_log` 累计 outputTokens+inputTokens，超日上限直接置 `blocked` 并提示；单次上限以 max_tokens 参数封顶。

## 四、响应式布局规则

- `LayoutBuilder`：宽度 ≥900 → NavigationRail（图标+标签，左侧）；<700 → NavigationBar（底部）；中间值 → Rail 折叠为纯图标
- 五个一级入口：灵感 / 提示词 / 资料库 / 用量 / 设置
- 列表-详情：宽屏双栏（MasterDetail 高度 ≥900 时启用），窄屏推入路由
- 所有 AI 按钮在「未配置可用模型」时 disabled + tooltip「请先在设置中配置 API Key」

## 五、AI 结构化输出统一约定

所有 Agent 任务 = 「系统提示词（含 JSON Schema 说明）+ 用户内容」，要求模型**只输出 JSON**；`structured_output.dart` 做：
1. 剥离 ```json 围栏 → jsonDecode
2. 按对应 Schema 校验必填字段与类型
3. 失败 → 将校验错误拼回消息重试，≤2 次；仍失败 → 任务 failed，错误展示给用户
